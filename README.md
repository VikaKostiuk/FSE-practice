# Практическая работа 2. Основы Python (Задачи A4–A7)

Данный репозиторий содержит решения задач базового уровня (A4–A7) по теме «Типы данных Python. Приведение типов. Решение задач на работу с числовыми данными».

## 📋 Краткое описание заданий

*   **A4.py — Нахождение максимума без ветвлений**
    Программа считывает два целых числа A и B и выводит наибольшее из них. По условию задачи запрещено использовать классические ветвления (`if/else`), циклы и функции. Решение реализовано с помощью тернарного оператора.
*   **A5.py — Проверка кратности без ветвлений**
    Программа проверяет, делится ли число A на число B нацело. Выводит "YES", если делится, и "NO" в противном случае. Использование ветвлений запрещено. Решение реализовано через тернарный оператор и оператор остатка от деления (`%`).
*   **A6.py — Электронные часы**
    Программа переводит количество секунд `N`, прошедших с начала суток, в формат времени `h:mm:ss`. Для форматирования вывода с обязательными ведущими нулями (для минут и секунд) используется функция `format()`.
*   **A7.py — Цвет шахматной клетки**
    Программа принимает координаты двух клеток шахматной доски. Если клетки одного цвета — выводит "YES" и цвет ("White" или "Black", считая (1,1) белой). Если разного — выводит "NO".

## 🛠 Требования

Для запуска программ необходим установленный **Python 3** 
*Примечание для пользователей macOS/Linux: в системе команда запуска обычно вызывается как `python3`, а не `python`.*
