# Задача B1 «Кот и мышь»

Практическая работа 3. Python 3.

## Задание

Кот и мышь ходят по замкнутой сетке, клетки задаются парой `(строка, столбец)`.

- Выход за край сетки переносит игрока на противоположную сторону.
- Если игроки попали в одну клетку, кот ловит мышь и игра заканчивается.
- Расстояние и пройденный путь считаются как `|Δстрока| + |Δстолбец|`.

Программа читает файл с данными и выводит:

1. таблицу позиций и расстояние между игроками на каждую команду `P`;
2. путь, пройденный котом и мышью;
3. исход игры: `Cat caught Mouse` или `Mouse evaded Cat`.

## Формат входного файла

| Строка | Значение |
|--------|----------|
| `28 24` | размер сетки (строки и столбцы) |
| `M 21 13` | начальная позиция или ход мыши |
| `C 27 8` | начальная позиция или ход кота |
| `P` | вывести текущее состояние |

## Запуск

Файлы `1.ChaseData.txt` ... `5.ChaseData.txt` должны лежать рядом с `B1.py`.

```bash
cd FSE-practice/Lab_3
python3 B1.py
```

Затем введите номер файла (от 1 до 5) и нажмите Enter. Результат появится на экране.

## Что использовано

Условные операторы `if / elif / else`, цикл `for` и `break`.
