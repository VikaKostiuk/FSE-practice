
# Задача B1 «Мониторинг осадков»

Практическая работа 4. Python 3.

## Задание

Программа читает файл с данными о суточных осадках за месяц, находит ошибки и формирует отчёт.

- Ошибка `Invalid`: указан недопустимый день для данного месяца.
- Ошибка `Repeated`: для одного дня есть несколько записей (остаётся первая).
- В отчёт попадают: список ошибок с номерами строк, гистограмма (одна `*` на каждые 0.25 дюйма или их часть, `NA` при отсутствии данных), а также минимум, максимум и среднее.

## Файлы

| Файл | Назначение |
|------|------------|
| `B1.py` | программа |
| `Precip.txt`, `Precip1.txt`, `Precip2.txt` | входные данные |
| `Report.txt`, `Report1.txt`, `Report2.txt` | отчёты (создаются программой) |

Входные файлы должны лежать в одной папке с `B1.py`.

## Запуск

```bash
cd FSE-practice/Lab_4
python3 B1.py
```

На запрос `Имя файла (Precip, Precip1 или Precip2):` введите имя входного файла без `.txt`, например `Precip1`, и нажмите Enter.

Отчёт будет записан рядом с программой: для `Precip` создаётся `Report.txt`, для `Precip1` создаётся `Report1.txt`, для `Precip2` создаётся `Report2.txt`.
